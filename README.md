# NativeScript UI Native Components

NativeScript components with the same API on every platform: Material on Android, native UIKit on iOS.

See [NATIVE_COMPONENTS_PLAN.md](NATIVE_COMPONENTS_PLAN.md) for the design and the status.

## Packages

All packages are in `packages/ui-*` (sources in `src/ui-*`): `ui-core`, `ui-switch`, `ui-progress`, `ui-activityindicator`, `ui-slider`, `ui-ripple`,
`ui-cardview`, `ui-button`, `ui-floatingactionbutton`, `ui-textfield`, `ui-textview`, `ui-bottomsheet`, `ui-snackbar`, `ui-dialogs`.

## Development

```bash
yarn install
yarn build
```
