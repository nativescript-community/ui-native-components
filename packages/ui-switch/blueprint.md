## Installation

```bash
npm install @nativescript-community/ui-switch
```

The Android components use **Material 3**: see the [repository README](https://github.com/nativescript-community/ui-native-components#installation) for the theme.

## Usage

```xml
<Switch checked="true" onBackgroundColor="#6750a4" />
```

## API

Same API as the core `Switch`, plus `onBackgroundColor` (track color when on).
